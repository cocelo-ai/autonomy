LiDAR는 Super-LIO와 Nav2에만 사용하고, elevation map은 선택된 카메라 PointCloud2만 병합해 사용한다. Super-LIO의 map → base_link 자세에서 roll/pitch를 제거해 카메라 포인트를 수평 보정한다.

  • Nav2의 /nav2/cmd_vel은 geometry_msgs/msg/Twist이다.
  • command_user_bridge가 이를 core/msg/CommandCore로 변환하여 /control_command/autopilot에 publish한다. linear.x, linear.y, angular.z는 각각 motion_command[0..2]이고 custom_drive_id는 2이다.
  • 최종 height map은 ROS 토픽으로 publish하지 않고, DDS core_dds::HeightMap (height_map, domain 1)으로만 전송한다.
  • 실행 설정은 elevation_mapping.yaml, super_lio_mid360.yaml, nav2_live.yaml 세 파일뿐이다.
